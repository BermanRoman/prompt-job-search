# Трудоустройство

Мастер-промпт помогает подготовить предложение для конкретной компании и должности по методологии Романа Бермана.

В режиме [кампании](campaign.md) агент берёт рутину поиска: фильтры и сохранённые поиски, отбор, персонализированные отклики, письма и ответы на анкеты в пределах разового поручения.

Для ATS работодателя и человека готовятся [две подачи резюме](resume.md) на общей подтверждённой фактуре.

На выходе — одна проверяемая задача, план решения, ограниченный образец работы, первая минута разговора, вопросы и список материалов к встрече.

Ни подготовка, ни выполнение кампании не обещают трудоустройства, роста дохода или измеренного повышения шансов.

## Кому подходит

Человеку, который хочет выбрать компанию и показать практическую работу по своему профилю, в том числе при недостатке формального опыта.

Обязательная квалификация, ограничения доступа и установленные компанией процедуры отбора сохраняются.

Обычные отклики можно вести параллельно с адресной подготовкой.

## Как пользоваться

1. Добавь [job-search.md](job-search.md) в инструкции проекта или передай агенту как точку входа.
2. Сделай доступными [workflow.md](workflow.md), [полную методичку](job-search-methodology.md), [контракт](contracts/work-evidence-v1.md), [роли](roles/reviewer.md), [нанимающего читателя](roles/target-reader.md) и [шаблон задачи](templates/task.md).
3. Напиши: «Начинаем подготовку к трудоустройству по инструкции и методичке».
4. По умолчанию согласовывай результаты шести шагов последовательно, либо прямо поручай подготовить пакет самостоятельно по имеющимся данным.

Для делегированного поиска вместо наставнического режима скажи, например: «Возьми поиск и отклики на себя; используй моё резюме и известные условия, уточни одним списком недостающее для кампании».

Сделай доступным весь репозиторий: агент начнёт с [campaign.md](campaign.md), [шаблона кампании](templates/campaign.md) и [resume.md](resume.md), а остальные файлы прочитает по необходимости.

Пользователь входит в HH и почту, агент работает через браузер, фиксирует критерии и объём отправки один раз; каждое соответствующее поручению письмо повторно согласовывать не требуется.

ATS и сайты компаний открываются тем же браузерным способом; API и почтовые коннекторы для выполнения не требуются и не подключаются.

Неизвестные факты, существенные решения и неподдерживаемые операции остаются явными исключениями, которые не останавливают независимую подготовку.

Для узкой правки готового предложения достаточно назвать материал и нужное изменение, весь процесс заново не запускается.

Агент читает карточки методички адресно по текущему шагу, сохраняя их приёмы и ограничения.

Отсутствующий файл запрашивается явно, методика не восстанавливается по памяти.

Работа возможна в среде с доступом к файлам или с переданными в чат документами, специальный сервис, соседний клон и скрипты для подготовки не нужны.

Для живой кампании нужны реальные средства доступа к каналам; сам репозиторий не является запущенным сервисом автооткликов.

Локальный Python 3 [журнал](scripts/README.md) убирает дубли, считает лимиты, связывает версии и блокирует повтор после неоднозначной отправки; сетевых вызовов в нём нет.

## Что собирается

| Шаг | Подготовленный результат |
|---|---|
| 1 | Точка старта, практические навыки, опыт поиска и ограничения. |
| 2 | Конкретная компания и роль: интерес, реалистичная ступень, причина кроме денег и статуса. |
| 3 | Участники решения и честный канал контакта с учётом HR и правил компании. |
| 4 | Одна задача с проверяемым результатом по выручке, издержкам, кадрам или времени. |
| 5 | План из пяти-шести шагов от результата назад и демонстрация с пределом времени, затрат и объёма. |
| 6 | Честная первая минута, вопросы, ответ на незнание и материалы с собой. |
| 7 — по желанию | Письмо после контакта и/или план на первый период. |

Шаг 7 предлагается один раз, отказ сохраняется при продолжении работы.

Письмо после встречи не обязательно и не отправляется автоматически.

Гипотеза задачи компании остаётся гипотезой до проверки, неизвестные показатели не заменяются вымышленными числами.

## Проверка и ограничения

Исполнитель готовит материал, независимый проверяющий возвращает конкретные замечания, а отдельный нанимающий читатель проверяет понимание только по предложению и публичному контексту.

Отзывы привязываются к SHA-256 текущих входов и артефакта, изменение версии требует новой проверки.

На исправления и проверку отводится не более трёх раундов суммарно на задачу, включая версии входов и перенос рабочего каталога.

После исчерпания предела нерешённые вопросы возвращаются пользователю со статусом `needs_author`, счётчик не обнуляется.

Если отдельного проверяющего или читателя нет, результат остаётся `needs_review` до исчерпания предела раундов, самопроверка не выдаётся за независимую.

Локальные случаи хранятся в исключённом из Git каталоге `runs/`, структура и возобновление описаны в [workflow.md](workflow.md).

При прямом делегировании полного выпуска проверенный пакет может получить `ready` без дополнительного согласования, если пользователь не сохранил за собой финальное решение.

Согласование подготовленного пакета само по себе не разрешает отправку; прямое поручение кампании может разрешить её сразу для определённых критериев, каналов и срока по campaign.md.

Все способы контакта честные, изображать клиента или курьера ради доступа нельзя, после явного отказа повторного захода нет.

Отказ не служит доказательством личных качеств кандидата.

Методика не заменяет профильного специалиста в вопросах договора и оформления и не предлагает платить работодателю за право работать.

## Связанные материалы

[Конструктор найма персонала](https://github.com/BermanRoman/promt-hiring-staff) описывает подготовку найма со стороны работодателя.

Обе стороны независимы и используют версионный [общий контракт](contracts/work-evidence-v1.md), сохраняя отдельные данные и полномочия.

Приватные материалы найма и оценки других кандидатов не передаются в работу соискателя автоматически или без прямого разрешения владельца на минимальный состав передачи по контракту.

Для редактуры предложения и письма доступны выборочные письменные карточки [инфостиля на bb091b6](https://github.com/BermanRoman/promt-copywriting/blob/bb091b6003f836106d09ed2bd5e91a8fb5d961dd/methodology-copywriting.md), без обязательного подключения и без требования авторского голоса.
