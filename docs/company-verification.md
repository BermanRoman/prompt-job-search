# Проверка поиска компаний — 06.11.2026

Проверена цепочка: профиль → пакет опубликованных вакансий → подбор компаний без найденной подходящей вакансии → Checko → сайты → фактическое место и дорога → опубликованный деловой контакт → адресное предложение.

Ссылка от человека пополняет очередь, но не завершает подбор; явное поручение «только эта компания» ограничивает объём с сохранением проверок.

## Код и независимое ревью

`python3 -m unittest discover -s tests -q` — 70 тестов прошли.

Независимое ревью выявило и после исправлений закрыло обход запрета контакта новым обращением, обход карточки через HH/ATS и обход истории новым ID при том же ИНН.

Карточка обязательна для каждого нового первого обращения, ИНН уникален и после заполнения неизменяем, запрет контакта действует на компанию целиком.

В проверенной дельте незакрытых P1/P2 не осталось.

## Границы результата

Реальных запросов Checko, оплаты, поиска персональных контактов и отправки писем в этой пробе не было.

Запись `sent` относится исключительно к синтетической квитанции, а не к доставленному письму.

Скрипт проверяет заполненность, сроки и историю заявленных доказательств; достоверность фактов требует содержательной проверки источников.

HTML — снимок состояния, перед действием заново проверяется общая SQLite-база.

Клиент поддерживает страницы поиска организаций; исчерпывающий обход страниц судебных и других подробных списков не реализован.

Экономия подтверждена только для повторного тестового запроса: дополнительного обращения к транспорту не произошло.

Проценты экономии токенов, качество живого подбора и эффективность писем не измерены.
